# HANDOFF — контекст проекта

Этот файл — «память» проекта, которая переезжает между компьютерами через git.
На новом компе: `bash sync.sh`, затем попроси ассистента «прочитай HANDOFF.md, продолжаем».
Обновляется перед каждым пушем (см. Журнал). **Без паролей** — репозиторий публичный.

### Деплой из ассистент-сессии (Git Bash + кириллический профиль)
`ssh.exe` в Git Bash игнорирует `HOME` и лезет в путь профиля `C:\Users\Рыба`, ломая
кириллицу в кодировке → не читает `~/.ssh` (ни ключ, ни known_hosts) → «Host key
verification failed». Обход — передать ASCII-пути явными флагами (ключ и known_hosts
можно скопировать в любой ASCII-каталог, напр. scratchpad):
```
ssh -i <ascii>/id_ed25519 -o UserKnownHostsFile=<ascii>/known_hosts \
    -o IdentitiesOnly=yes root@72.56.39.225 "..."
```
Так же гнать `tar -C out -czf - . | ssh ... "cd /var/www/... && tar -xzf -"`.
