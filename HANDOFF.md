# HANDOFF — контекст проекта

Этот файл — «память» проекта, которая переезжает между компьютерами через git.
На новом компе: `bash sync.sh`, затем попроси ассистента «прочитай HANDOFF.md, продолжаем».
Обновляется перед каждым пушем (см. Журнал). **Без паролей** — репозиторий публичный.

Причина — два наложившихся эффекта флексбокса: (1) у самого длинного текста `min-width:auto` (дефолт у флекс-элементов) раздвигал ЕГО круг шире заданных `flex:0 0 40%`, раз содержимое не помещалось; (2) `align-items:stretch` (дефолт на `.ph-circles`) следом растягивал ДВА ДРУГИХ круга по высоте вслед за получившимся более высоким соседом — итог: соседние круги 166×183 (овал), длинный — 183×183 (круг, но крупнее). Фикс: `min-width:0` на `.ph-circle` (контент больше не раздвигает круг) + `align-items:flex-start` на `.ph-circles` (круги не тянутся по высоте друг за другом); чтобы длинный текст поместился без роста бокса — паддинг 10%→8%, шрифт 0.92rem→0.82rem с `line-height:1.3`. ### Деплой из ассистент-сессии (Git Bash + кириллический профиль)
`ssh.exe` в Git Bash игнорирует `HOME` и лезет в путь профиля `C:\Users\Рыба`, ломая
кириллицу в кодировке → не читает `~/.ssh` (ни ключ, ни known_hosts) → «Host key
verification failed». Обход — передать ASCII-пути явными флагами (ключ и known_hosts
можно скопировать в любой ASCII-каталог, напр. scratchpad):
```
ssh -i <ascii>/id_ed25519 -o UserKnownHostsFile=<ascii>/known_hosts \
    -o IdentitiesOnly=yes root@72.56.39.225 "..."
```
Так же гнать `tar -C out -czf - . | ssh ... "cd /var/www/... && tar -xzf -"`.
